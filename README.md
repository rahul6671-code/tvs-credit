# TVS Credit Residual Engine

1. Put `Analytics Case Study Dataset.xlsx` in this folder.
2. Open `TVS_Residual_Engine.ipynb` in Jupyter.
3. Run every cell from top to bottom.
4. Confirm the model-comparison table and selected model.
5. Start the dashboard: `streamlit run app.py`.

The notebook exports agreement-level recommendations, model metrics, risk-band strategy, metadata, and the trained pipeline.

Important: recommendation rules are prototype policy guardrails. Validate them through a champion–challenger pilot before production use.
